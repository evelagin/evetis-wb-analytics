# DATA_MODEL.md

## Основные сущности проекта

### SKU

SKU — внутренняя товарная единица EVETIS.

Основные идентификаторы:
- internal_sku
- nmId
- barcode
- vendorCode
- subject
- product_name

### Заказ

Заказ — факт оформления заказа покупателем на WB.

Источник:
- WB API Orders

### Продажа

Продажа — факт выкупа товара покупателем.

Источник:
- WB API Sales
- WB Finance report

### Возврат

Возврат — обратное движение товара/денег.

Источник:
- WB API Sales/Returns
- WB Finance report

### Себестоимость

Себестоимость берется из COST_HISTORY.

Для наборов себестоимость считается через BUNDLES.

### Реклама

Реклама учитывается двумя способами:
- факт удержаний в PNL_TOTAL;
- аналитика кампаний отдельно.

### Прибыль

Управленческая прибыль считается как:

выручка / выплаты / реализация
минус:
- комиссия WB,
- логистика,
- хранение,
- удержания,
- эквайринг,
- реклама,
- себестоимость,
- налоги, если они включены в модель.

## Границы наблюдаемости источника

Константы, фиксирующие даты, с которых WB изменил объём раскрытия данных.
Пересекать их при сравнении периодов нельзя — расхождение будет свойством
источника, а не наших данных.

### `WAREHOUSE_DISCLOSURE_DEGRADED_FROM = 2026-08-15`

С этой даты WB прекратил раскрывать движение по конкретным складам РФ.

Что это означает для остатков:

- **Наблюдаемо:** суммарный остаток (`Всего находится на складах`), агрегат
  `Склад WB РФ`, движение внутри агрегата, товар в пути.
- **Не наблюдаемо:** движение по поимённым складам. Их строки WB отдаёт
  побайтово неизменными.

Формулировка, обязательная к использованию вместо «named stock frozen»:

> **named warehouse movement is not observable after WB anonymization;
> totals remain observable**

Ровный ряд по поимённому складу **не является** доказательством того, что товар
не продаётся. Он доказывает только то, что WB не раскрывает движение.

Смежное следствие в финансах: с отчётов за **13.08.2026** поле `office_name`
в детализациях к отчётам реализации сведено с 37 значений к 4. История до 12.08
включительно WB не переписывал (проверено 26.08.2026). Поля `warehouse_name` и
`region_name` в `RAW_WB_FINANCE` пусты на 100% строк.

Источник: WB API Release Notes, запись от 15.08.2026.
