(см. PREWRITE_GO_NO_GO в отчёте гейта).

| файл | что внутри |
| --- | --- |
| `pre6a_metadata.json` | геометрия, заморозка, число объединений и правил УФ, высоты строк и ширины колонок, sha256 значений и форматов, отпечаток WB |

| `pre6a_OZON_merges.json` | все 1 483 объединения |
| `pre6a_OZON_cf.json` | условное форматирование (в боевом листе его нет: 0 правил) |

**Форматы в репозиторий не положены намеренно.** Полный `userEnteredFormat` на 465 × 404 —
96 МБ; в Git такому не место. Его sha256 записан в `pre6a_metadata.json`
(`formatsSha256`), и блоб пересобирается тем же запросом за пару минут. Проверка отката по
форматам делается сравнением хеша, а не хранением блоба.

Состояние на момент снимка: OZON 465 × 404, 1 483 объединения, 0 правил УФ, 0 защищённых
диапазонов, заморозки нет. WB 803 × 623, 2 475 объединений, 2 именованных диапазона.
