# baseline_pre_t2 — историческое тестовое доказательство

**Это не исполняемый production-код.** Это побайтная копия `pipelines/ozon/runtime` на
коммите `dc7fda4`, то есть Ozon runtime **до** Tenancy T2. Этот же код собран в
production-образ `ozon-runtime-ingest@sha256:24e3c6d6…`. Подробности, sha256 и git blob id
каждого файла — в `PROVENANCE.json`.

Назначение — эталон различающего прогона `../../test_differential_compat.py`:
текущий runtime с конфигурацией EVETIS обязан вести себя так же, кроме двух перечисленных
разниц (D1 — вырезание секретов, D2 — вывод сбоя журнала).

Правила:
- **не редактировать и не форматировать.** Тест сверяет sha256 и git blob id с
  `PROVENANCE.json`, любое изменение байтов его роняет. Форматтеров в репозитории нет;
  если они появятся, этот каталог надо исключить.
- **не импортировать** из `pipelines/ozon/runtime`, `pipelines/ozon/bootstrap` и
  инфраструктуры. Запускается только подпроцессом драйвера `../driver.py`.
- **в образ не попадает.** Образ собирается из контекста `pipelines/ozon/runtime`, файлы
  копируются поимённо.
- Секретов здесь нет: код читает их из Secret Manager по имени. Проверено сканированием.
