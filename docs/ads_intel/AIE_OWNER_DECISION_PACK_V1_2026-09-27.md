  `knowledge_ts = D+1 09:00 МСК`; `FACT_ADS_SKU_DAILY` пересобирается из RAW по `load_ts ≤ knowledge_ts`.
- **Паритет:** реконструкция «на сейчас» совпадает с production `FACT_ADS_SKU_DAILY` по 6 112 ключам и всем мерам,
  неразбираемых `load_ts` 0 (`python tools/aie_backtest.py parity`).
- **Детерминизм:** повтор дня 2026-09-12 — решения, сетка и исходы побайтно совпали; классы запросов совпали,
  числа отличаются только в последнем разряде FLOAT64 (≤ 4,8·10⁻¹⁶, унаследовано от сумм FLOAT64 Ads-4).
- **Инварианты replay (все PASS):** без политики нет INCREASE/DECREASE/HOLD; Ozon никогда не направляющий и не
  production-grade; INCREASE только при заданном P1; одно решение на пару × дату × политику; у каждой строки есть

## 3. Решения владельца: варианты и их последствия на истории

### P3 — уровень доверия (при P6 = фактическая база, P1 не задан)

| Вариант | DECREASE (решений / пар) | HOLD | интервал пересекает лимит | Следствие |
|---|---|---:|---:|---|
| 0,80 | 100 / 10 | 129 | 84 | больше понижений, больше риск ложного |
| 0,90 | 89 / 8 | 115 | 109 | промежуточно |
| 0,95 | 86 / 7 | 108 | 119 | меньше понижений, больше «недостаточно данных» |

Разница между 0,80 и 0,95 — 14 решений DECREASE и 3 пары за 62 дня. Понижения сосредоточены на немногих SKU:
EVT-HC-HAND-300 (3 кампании), EVT-FT-ACNE-150, EVT-HC-AMBER-300.

### P1 — целевой ДРР (резерв) и P2 — гистерезис

- **На истории INCREASE не возникает ни при одном варианте** P1 ∈ {0,1 … 0,5}, P2 ∈ {0; 1; 2 п.п.}, P5 ∈ {0; 14; 20; 45},
  кроме одного решения при P3 = 0,80, P1 = 0,10.
- Причина — не P1. Кандидаты на повышение есть: при P3 = 0,90 их 76 / 52 / 35 / 29 / 26 для P1 = 0,1 … 0,5.
  Но **все они до 2026-09-10**, когда покрытие запасом ещё не наблюдалось, и все остановлены
  `INV_COVER_UNAVAILABLE`. После 10.09 кандидатов нет: окна сжаты P7.
- P2 сокращает кандидатов слабо: при P1 = 0,1 — 76 → 65 → 61 для 0 / 1 / 2 п.п.
- Главное влияние P1 сейчас — на состав HOLD: при P1 = 0,1 → 76 удержаны запасом и 20 «интервал пересекает цель»;
  при P1 = 0,5 → 26 и 50, плюс 20 «между целью и лимитом».
- **Вывод для решения:** на истории EVETIS выбор P1 и P2 не меняет выдачу, но определит поведение, когда
  появится история покрытия и длинные окна без смены цены. Допустимый вариант — «INCREASE в V1 не выдавать»
  (P1 = NULL сохраняется).

### P5 — минимальное покрытие запасом

- **На истории последствия не измеримы:** все кандидаты на повышение — до начала истории покрытия (10.09). При
  любом P5 результат одинаков.
- Для наборов покрытие не наблюдается никогда (CT считает компоненты), поэтому повышение для наборов будет
  удерживаться `INV_COVER_UNAVAILABLE` при любом P5.
- Опоры для выбора (конвенции владельца, не выведенные из рекламы): 14 = срок поставки WB 7 + страховой 7;
  20 = Ozon 10 + 10; 45 = целевое покрытие C0 D4.

### P13 — период ожидания

- Переключений INCREASE ↔ DECREASE на истории **0** при любом варианте 0 / 3 / 7 / 14 суток: INCREASE почти не бывает,
  а обрезка окна по смене ставки уже заставляет копить новую выборку.
- Медиана длительности состояния — 9–11 суток, p90 — 37–38 суток.
- **Вывод:** на текущих объёмах P13 не меняет выдачу. Его стоит решить вместе с P1 — когда появятся повышения.

### P15 — множители диагностики Ads-4

- 14 645 строк «запрос × дата» (с 2026-08-14). Доля `Q_HIGH_CPC`: 193 / 198 / 208 / 220 строк для 0,5/1,5 … 0,8/1,2.
  Остальные классы от множителей не зависят.
- На состояния решений множители не влияют (только диагностика).
- 99 % строк — `Q_INSUFFICIENT`: на уровне запросов объёма почти нет.

### P6 — база лимита (не в запросе на решение, но не решено)

- Replay возможен только на фактической базе: прогнозная — только текущая.
- На 26.09 доказательных пар нет (окна сжаты P7), поэтому выдача одинакова при всех четырёх базах.

## 4. Наблюдаемые последствия (не причинные)

Для решений сетки «P3, P1 = NULL» сравнивался ДРР следующих 28 суток с безубыточностью тех же 28 суток:

- после `DECREASE` ДРР оставался выше лимита в 61–88 % случаев;
- после `HOLD` без смены настроек — в 3 %;
- после `HOLD` со сменой — в 34–38 %.

Это согласуется с тем, что сигнал различает экономику. Но выборки пересекаются: соседние даты, одни и те же 8–10 пар. Действия владельца не
случайны, поэтому причинного вывода нет. Для него нужен эксперимент (holdout или switchback на уровне кампании).

## 5. Случаи для ручного разбора

- **Завершённые кампании в составе:** 855 решений (40 % WB). Состав «расход за 28 суток» включает кампании,
  уже завершённые (статус 7). Это не порог, а определение состава — решение владельца, показывать ли их.
- **Нулевой остаток при расходе:** 9 пар; крупнейшие — EVT-FC-MOIST-50 (3 292 ₽ за 28 суток при остатке 0),
  EVT-SET-4PC-ACNE, EVT-SET-TON-SER-CREAM-ACNE.
- **Ads-4 POTENTIAL_WASTE:** 6 пар; крупнейшие — EVT-HC-HAND-300 (кампания 37669244), EVT-SET-TON-SER-CREAM-ACNE,
  EVT-HC-AMBER-300.
- **P7 сжал окно при заметном расходе:** 16 пар, например EVT-HC-HAND-300 и EVT-FS-ACNE-30 на 25.09.
- **Структурная пауза по экономике (текущий режим):** EVT-HC-HAND-300 — прогноз WB_FE_V1 BELOW_BREAK_EVEN
  (−6,3 %). Крем для рук ранее назывался владельцем исключением — это вопрос P4.
