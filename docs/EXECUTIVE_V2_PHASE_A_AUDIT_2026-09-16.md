## K. Риски и ограничения Metabase (v0.63 OSS)

1. **Доступ.** Chrome-расширение блокирует localhost. Без разрешения Phase B через UI невозможна.
2. **Smartscalar показывает только % изменения** (плюс прошлое значение). Δ ₽ и Δ п.п. одновременно не выводятся. Решение: Δ п.п. и Δ ₽ считаются в SQL карточки, отдельной колонкой. Выводятся как мелкая соседняя плитка или «detail» строкой.
3. **% изменения при смене знака бессмысленен** (−5 484 против +8 351). Для прибыли и маржинального дохода сравнение выводится в Δ ₽. Карточка 53 уже скрывает сравнение при смене знака; это поведение сохраняется.
4. **Условной окраски у scalar/smartscalar нет** (есть только стрелка сравнения). «Сдержанный красный при убытке» для плитки прибыли нативно недоступен. Варианты: (а) окраска стрелки изменения; (б) text-карточка с эмодзи-маркером ●, собранная SQL-ом; (в) принять без окраски.
5. **Стрелок и операторов между плитками нет.** «−», «=», «→» делаются узкими text-карточками. На мобильной ширине они переносятся.
6. **Иерархия размеров** задаётся только размером ячейки. Шрифт числа масштабируется автоматически, минимальная высота плитки со сравнением — 3.
7. **Tooltip:** сейчас это описание карточки (`description`), в нём технический текст. В V2 пользовательский текст пишется в dashcard-override `card.description` (проверить в 0.63), технический контракт остаётся в описании карточки. Если override недоступен — нужны новые карточки-обёртки, иначе пострадает документация контракта.
8. **Переиспользование карточки дважды** (49 в секциях 3 и 6) допустимо: один источник, два dashcard.
9. **Скрытие нулевой компенсации:** SQL не возвращает строк при 0 + «скрывать, если нет результатов».
10. **Фильтр периода:** все новые карточки обязаны иметь mapping `date → template-tag day`. Header-статус частично глобальный (свежесть), частично по периоду.
11. **Откат:** перед Phase B нужен снимок `tools/metabase_export_snapshot.sh` и rollback-скрипт (прецедент — Control Tower).
12. **Производительность:** 25–30 BigQuery-запросов на открытие. Сейчас ~27, объём сопоставим.
