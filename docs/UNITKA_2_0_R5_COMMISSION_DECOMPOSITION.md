## 2. Откуда взялся разрыв 43,8 % против 45,32 %

Ставка маркетплейса менялась внутри 2026 года. Взвешенные величины по месяцам
(по дате продажи):

| месяц | `commission_percent` | эквайринг, % от базы продавца | **эффективная суммарная** | реализованная СПП |
|---|---|---|---|---|
| 05.2026 крем | 34,50 % | 2,276 % | **36,776 %** | 42,22 % |
| 06.2026 крем | 34,50 % | 2,157 % | **36,657 %** | 44,35 % |
| 07.2026 крем | 32,5…42,25 % (переход) | 2,186 % | **39,866 %** | 43,30 % |
| 08.2026 крем | 42,25 % | 3,143 % | **45,392 %** | 17,45 % |
| 09.2026 крем (1–9) | 42,25 % | 3,067 % | **45,316 %** | 21,97 % |

Две независимые причины сложились:

1. **Базовая ставка выросла 34,5 % → 42,25 %** в июле 2026 (июль — переходный месяц,
   в нём встречаются обе ставки на разных строках).
2. **СПП обвалилась с ~43 % до ~17–22 %** — и это подняло эквайринг, выраженный
   в процентах от цены продавца (механику см. §3).

Запомнившиеся владельцу «42,5 % + 1,3 % = 43,8 %» ни одному наблюдаемому месяцу
не соответствуют. 42,5 близко к текущим 42,25. А **1,3 % эквайринга в данных не
встречается ни разу**: даже при максимальной наблюдавшейся СПП 44 % расчёт даёт
4 % × 0,56 = 2,24 % от цены продавца. Чтобы получить 1,3 %, нужна СПП ≈ 67 %.
Это цифра другого тарифного периода, до перехода WB на собственный банк.

## 3. Что такое «1,66–4,88 %» — и почему это НЕ разброс тарифа

Поле WB `acquiringPercent` — это **производное отношение** `acquiring_fee / базу продавца`,
а не тариф. Настоящий тариф считается от другой базы.

**Эквайринг = 4,00 % от суммы, которую фактически заплатил покупатель (`retailAmount`).**

Проверка на 2 228 строках (01.06–09.09), группировка по `acquiring_fee / retail_amount`:

| ставка от суммы покупателя | строк | доля |
|---|---|---|
| **4,00 %** | 1 692 | 75,9 % |
| **4,88 %** | 321 | 14,4 % |
| 0,40 % | 62 | 2,8 % |
| 2,5 / 2,3 / 1,69 / 1,55 / 3,5 % … | остальные | ~6,9 % |

Внутри каждой группы значения `acquiringPercent` от WB разные (3,88 / 2,71 / 2,13 / 3,10 …),
а отношение к сумме покупателя — ровно **4,000**. Это тарифы способов оплаты
(`paymentProcessing` = «Компенсация платёжных услуг», `acquiringBank` = «Вайлдберриз Банк»);
0,4 % — кошелёк, 4,88 % — оплата частями.

Отсюда механика, объясняющая всю картину:

```
эквайринг, % от цены продавца  =  4 %  ×  (1 − СПП)
```

| месяц | 4 % × (1 − СПП) | фактический эквайринг, % от базы | расхождение |
|---|---|---|---|
| 05.2026 крем | 2,311 | 2,276 | 0,035 п.п. |
| 06.2026 крем | 2,226 | 2,157 | 0,069 п.п. |
| 07.2026 крем | 2,268 | 2,186 | 0,082 п.п. |
| 08.2026 крем | 3,302 | 3,143 | 0,159 п.п. |
| 09.2026 крем | 3,121 | 3,067 | 0,054 п.п. |

Остаточное расхождение — доля покупателей с не-4 % способом оплаты.

## 4. Рекомендуемая операционная модель

**Текущее значение 45,32 % в сентябрьском блоке — подтверждено.**
Реализованная эффективная ставка по крему: 45,3155 % за сентябрь, 45,3747 % за 01.08–09.09.
Менять число не требуется.

Но хранить его как один константный процент — хрупко: он развалится, как только
изменится СПП или тариф. Предлагается разложить на две части, каждая со своим драйвером:

| компонент | модель | почему так |
|---|---|---|
| комиссия маркетплейса | **42,25 % × цена продавца** — фиксированная ставка из тарифа WB | детерминирована, сходится до копейки на 705 наблюдениях |
| эквайринг | **4,00 % × цена продавца × (1 − СПП)** | тариф платёжной услуги от суммы покупателя |
| итого к отображению | сумма двух | при СПП 22 % даёт 42,25 + 3,12 = **45,37 %** |

Преимущество: при следующем изменении СПП или тарифа ставка пересчитается сама,
а не станет молча неверной.

**Требует решения владельца.** До одобрения в книге остаётся 45,32 %.
