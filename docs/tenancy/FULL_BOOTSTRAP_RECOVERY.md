# Source-free FULL bootstrap provenance migration

The controller entrypoint and imported FULL backend share the pause exception in
`cloud_tick`. Executing the entrypoint through `python -m` must not redefine that
exception: a staged PAUSED boundary is QUIESCENT_PAUSED, with no lease, intent,
receipt or source call. Other gate failures still STOP. Exact packaged image
qualification exercises the separate entrypoint/import namespaces.

`PAUSED_ENTRYPOINT_EXCEPTION_IDENTITY_V1` is an owner-attested, additive authority
record for a proven source-free bootstrap failure. It is not a generic STOP
exemption and does not resume the failed root. The original root, manifest, GO,
STOP, selected leaf and shard remain unchanged. A separately qualified image
requires a new provenance root, its own manifest/GO and paused cloud bootstrap.

The semantic comparison preserves every field other than controller provenance,
root digest and qualification references: tenant, runtime, creation origin,
cutoff, boundaries, eleven domains, T5 parents, leaves, retained Supplies, caps,
Prices/Stocks observation semantics and Finance provisional-finality limitations.
No changed date, business scope or runtime is eligible under this primitive.

Every closed predicate must be proven with fresh metadata and bounded SELECT:
exact failed execution, deterministic exception defect, PAUSED source boundary,
no Seller/Performance request, intent, receipt, child, journal or persisted source
rows, valid binding/security, no active/conflicting lease, all Jobs inactive and
all Schedulers PAUSED, exact replacement image qualification, and original STOP
preservation. Unknown is BLOCKED. The owner-only ref marker and additive old-root
record authorize no source dispatch; normal cloud append cannot create that marker.

Activation remains separate and requires every existing live FULL GO predicate,
source-free paused bootstrap proof and reviewed dedicated-tick-only activation.
Ordinary Schedulers stay PAUSED. FULL started is reported only after a natural
cloud-owned source execution, persisted reconciliation and coverage progression.
