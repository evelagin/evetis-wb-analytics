# План перехода

Порядок шагов, а не список пожеланий. У каждого шага: зачем, что именно делается, чем
проверяется, как откатывается и чьё решение требуется. Шаги независимы, если не сказано иное,
и ни один не блокирует текущие бизнес-приоритеты (стабилизация Ozon Unit, загрузка следующих
месяцев, ежедневное обновление, стабильность WB Unit, Operations Center, отчётность Metabase).

**Легенда риска:** 🟢 только Git и чтение · 🟡 меняет production предсказуемо и обратимо ·
🔴 необратимо или с широким радиусом.

## Что сознательно НЕ в плане

- миграция на dbt / Dataform / Dagster (ADR-01, ADR-02);
- отдельный сервер автономных агентов (ADR-04) — после фазы 2;
- переписывание Apps Script;
- автоматическое исправление production агентом;
- любые новые компоненты с правом записи во внешние сервисы, пока открыта F-18.
