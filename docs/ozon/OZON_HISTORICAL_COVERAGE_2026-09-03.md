## Остатки — почему матрица их не содержит

`STOCK_HISTORY_START = 2026-08-31`. Ozon отдаёт остатки только на момент вызова.
Восстановить прошлые остатки нечем, и делать этого нельзя: ни из продаж, ни
интерполяцией, ни псевдо-снимками. Колонки для остатков в матрице нет намеренно —
чтобы её нельзя было прочитать как «за 2025 год остатков не было».

Проверка: строк с `snapshot_date < 2026-08-31` — **0**.
