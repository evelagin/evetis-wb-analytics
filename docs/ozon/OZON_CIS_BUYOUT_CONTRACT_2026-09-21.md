# Контракт операции «Выкуп товара у селлера» (CIS/Беларусь)

Дата: 2026-09-21 · Gate 5K · Статус: Git-first, **не развёрнуто**

## 1. Что это за операция

Часть заказов из Беларуси Ozon не продаёт как агент, а **выкупает у продавца**. Это другая
хозяйственная форма, а не частный случай обычной продажи.

Первичный документ — **«Отчёт о выкупленных товарах»** (`RealizationReportCIS-*.xlsx`). В нём:

| | обычная реализация | выкуп |
| --- | --- | --- |
| роль Ozon | Получатель (агент) | **Покупатель** |
| роль владельца | Плательщик | **Продавец** |
| документ | «Отчёт о реализации» / «Позаказный отчёт о реализации» | «Отчёт о выкупленных товарах» |
| колонка ставки | «Вознаграждение за продажу по категории» (0,39 / 0,41) | «**Дисконт по категории, %**» (21 … 44) |
| выручка продавца | цена продавца | **цена реализации = справочная × (1 − дисконт)** |
| комиссия | есть | **не существует как факт** |
| эквайринг | есть | нет |
| логистика | есть | **есть** (остаётся расходом продавца) |

«Дисконт по категории» **нельзя называть комиссией**: это скидка к справочной цене, по которой
Ozon выкупает товар, а не вознаграждение за услугу. Агентское вознаграждение у Ozon оформляется
отдельным УПД (апрель 2026 — УПД №44459516, 596,67 + НДС 131,27 = 727,94 ₽) и в основной акт
услуг (УПД №26726670, 37 672,09 ₽) не входит.

## 2. Доказательство

**Цепочка документов сходится по номеру, а не только по сумме:**

```
Отчёт о выкупленных товарах №4580668            итого 1 600,60 ₽
  → Отчёт о взаиморасчётах, строка
    «Выкуп товара у селлера» №4580668 от 16.04.2026     1 600,60 ₽
    → Платёжное поручение №424214 от 21.04.2026         1 600,60 ₽
```

**Потоки не пересекаются.** Ни одно из 30 отправлений-выкупов не встречается:

- в «Позаказном отчёте о реализации» — 163 отправления за апрель 2026, у каждого есть номер отправления;
- в детальном отчёте по эквайрингу — 152 строки;
- в детальном отчёте ПВЗ/курьеров — 172 строки.

**Арифметика точна:** `цена реализации = справочная цена × (1 − дисконт)` выполняется в 30 строках
из 30, до копейки. Справочная цена в документе совпадает с `price_rub` отправления в 30 случаях из 30.

**Структурная сигнатура в BigQuery.** У выкупа `status = 'delivered'`, `payout_rub = 0`,
`commission_amount_rub = NULL`, начислений с выручкой нет — только логистика. У обычной продажи
того же SKU в том же месяце заполнены `seller_base_price_rub`, `buyer_paid_price_rub`,
`commission_rub` и `commission_ratio`.

## 3. Ставки берутся из документа и не экстраполируются

Наблюдённые дисконты: **21,0 / 30,5 / 33,0 / 37,0 / 42,0 / 44,0 %**.

Ставка 21 % встречается **ровно один раз** (отправление `84981214-0073-1` от 16.05.2025) и ни из
чего не выводится. Это и есть причина запрета на экстраполяцию: любая «средняя» или «соседняя»
ставка дала бы здесь неверную сумму.

## 4. Модель в витрине

`ozon_mart.V_OZON_CIS_BUYOUT` — 30 отправлений с суммой выкупа по документу, зерно
`posting_number`, провенанс — номер документа и его период.

`FCT_OZON_SKU_PNL_DAILY` и оба месячных P&L различают тип операции:

| | `MARKETPLACE_SALE` | `CIS_BUYOUT` |
| --- | --- | --- |
| выручка | цена продавца из начислений | сумма выкупа из документа |
| комиссия | из начислений | **0, и это NOT_APPLICABLE** |
| `commission_missing_qty` | >0, если комиссии нет в источнике | **всегда 0** |
| `commission_not_applicable_qty` | 0 | количество |
| логистика, себестоимость | как обычно | как обычно |

Полнота комиссии имеет **три** состояния, а не два: `PRESENT`, `MISSING`, `NOT_APPLICABLE`.
Считать выкуп «неполными данными» — значит сообщать о пробеле, которого нет.

## 5. Выкуп без документа

За 05–08.2026 «Отчётов о выкупленных товарах» в архиве нет. Пять отправлений
(`0136161223-0034-1`, `0144805755-0262-1`, `0151252173-0059-1`, `91224369-0020-1`,
`0155570588-0181-2`, справочная выручка 6 929 ₽) классифицированы как выкуп по структурной
сигнатуре, но **сумма выкупа не доказана**.

Политика: такая строка несёт справочную цену в выручке и одновременно
`buyout_revenue_unproven_qty` / `buyout_revenue_unproven_rub`. Величина непроверенной выручки
названа и измерена, а не спрятана и не выдумана. `economics_covered` для неё ложно.

Если ставка окажется 44 %, завышение составит 3 048,76 ₽. Закрыть можно только документом.

Май–сентябрь — ноль. Изменилось 2 ячейки (выручка и комиссия 25.04).
