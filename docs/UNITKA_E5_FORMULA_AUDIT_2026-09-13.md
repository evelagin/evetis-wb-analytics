## 8. ДРР — разбор формулы и что добавить (OWNER DECISION, ничего не изменено)

**Как считается сейчас.** По SKU за день: `ДРР = X / ((Q − N) · AC)` — расходы на внутреннюю
рекламу WB / выручка по заказам (без блогеров и самовыкупов) по цене **с СПП** (что платит
покупатель). Сводка дня и месяц (сентябрь): `J / Σ_SKU((Q − N)·AC)` — взвешенно, верно. История —
`AVERAGEIF` дневных (§3), неверно.

**Вердикт по маркетинговой грамотности: формула корректна как «ДРР по заказам»** — это
общепринятая метрика WB-кабинета и она сопоставима из месяца в месяц. Три оговорки:
(1) знаменатель по цене с СПП: СПП финансирует WB, продавец получает `AA·(1 − комиссия)`, поэтому
при ненулевой СПП ДРР «в деньгах продавца» выше показанного (в сентябре `AB` пуст — расхождения
нет); (2) ДРР дня сравнивает рекламу дня с заказами того же дня — без лага атрибуции (норма для
ежедневки); (3) ДРР сам по себе не отвечает на вопрос владельца «сколько осталось после всех
расходов маркетплейса и маркетинга».

**Чего не хватает для решений (и что уже есть в книге).** Ответ на вопрос владельца в книге
**уже есть** — это `W` «Доходность (общая)» = `Q·AI − X − AG − отмены + Y`, где `AI` = цена −
комиссия − логистика − налог − COGS. Нет **порога**, с которым сравнивать ДРР:

* **Break-even ДРР (безубыточная доля рекламы)** = `AI / AC` — какую долю выручки можно отдать
  рекламе, чтобы заказ не ушёл в минус (без хранения и отмен; с ними — `(AI − AG/Q − S/Q·(AI+AF+RL)) / AC`).
* **Прибыль на заказ после рекламы** = `W / Q` — уже есть (`V`).
* **Правило STOP/SCALE**: `ДРР > BE-ДРР` — реклама уничтожает маржу (STOP/снижать ставки);
  `ДРР ≤ BE-ДРР − целевая маржа` — можно масштабировать.

рекламы **−7 447 ₽** — реклама съедает всю маржу с запасом.
