## 1. Что именно выравнивалось

Для каждого из 23 неэталонных блоков приведено к эталону:

| группа | как сделано |
|---|---|
| ширины колонок (24 на блок) | `s8cwidth` — один `updateDimensionProperties` на все 576 колонок |
| фон, границы, выравнивание, перенос, шрифт, формат числа, отступы, поворот | `s8cfmt` — `copyPaste` с `pasteType: PASTE_FORMAT` с эталона на каждый блок |
| высота строк 735–768 | не требовалось: строки общие для всех блоков (736 — 76 px, остальные 18 px) |
| условное форматирование (выходные, приглушение будущего, оборачиваемость, ДРР, отмены, трафик, знак доходности, «был трафик — нет заказов») | `s8repro_`, `s8crestore`, `s8cgfix`, `s8cclone` — см. §3 |
| левая сводка `A:K` | тот же статический стандарт, `SUMMARY VISUAL QA = PASS` |

Ничего нового не придумывалось: источник каждого свойства — эталон.

## 2. Идентификация товара

Строка 735 (название SKU) не менялась — она и есть индивидуальность товара.
Строка 736 (шапка колонок) приведена к эталону, потому что её прежний плоский
«товарный» фон конфликтовал с группами AUTO / MANUAL / MODEL / FORMULA, которые
в эталоне и различают типы колонок.

Исторические цвета шапок сохранены в Script Property `S8_IDENT_RB`. Готова, но
**не запущена**, функция `s8cband()` — вернуть историческую краску товара полосой
на строку 735, не трогая структуру колонок. Это решение владельца.

## 3. Условное форматирование: три находки

### 3.1 Градиент нельзя расширять одним правилом на все блоки

У градиентного правила шкала MIN / PERCENTILE / MAX считается **по всем его
диапазонам сразу**. Когда 23 блока были до-даны в те же правила (`s8crestore`),
шкала пересчиталась и **вид эталона поехал на 8 ячейках** (`W739`, `W741`–`W747`) —
замерено, не предположено.

Исправление `s8cgfix`: 8 таких правил развязаны — эталону вернули ровно его
исходные диапазоны, каждому из 23 блоков создано **своё** правило с той же
палитрой и той же логикой, шкала считается внутри блока.
`ГРАДИЕНТЫ ЭТАЛОНА ВОЗВРАЩЕНЫ = 8 / 8`, вид эталона вернулся на тех же 8 ячейках.

Следствие, которое надо знать владельцу: цвет градиента сравним **внутри одного
SKU**, а не между SKU. Это то же поведение, что уже было принято для доходности.

### 3.2 Проверка покрытия УФ считала по номеру правила — и потому всегда врала

Старая метрика включала в отпечаток блока **индекс правила**. Но часть дизайна
принципиально живёт отдельным правилом на блок (градиенты, приглушение будущих
дней). Такие блоки метрика объявляла расхождением всегда — отсюда прежнее
«покрытие 0 из 23» при фактически одинаковом виде.

Новая метрика (`s8cfp_` / `s8ccfqa`) сравнивает **эффект**: условие + формат +
колонки + строки, где ссылки в формуле нормализованы в смещения (относительные —
от якоря правила, абсолютные внутри блока — от начала блока, зеркало `$WB$736`
остаётся как есть). «То же оформление другим правилом» теперь считается
совпадением, «нет оформления» — расхождением.

### 3.3 Одно оформление действительно отсутствовало у 23 блоков

После честной метрики осталось ровно одно: **«был трафик — нет заказов»**,
жёлтая заливка `#fce8b2` на колонке «Заказы факт», условие
`AND(дата ≤ TODAY(); показы > 0; заказы = 0)`. Оно было только у эталона.
`s8cclone` создал 23 копии.

Важная деталь, на которой первая попытка сломалась: Sheets хранит формулу УФ
так, как она применяется к **левому верхнему углу первого диапазона правила**.
У правила-источника первый диапазон был в сводке (`F737`), поэтому `D737` в его
формуле означало «на две колонки левее». При переносе в однодиапазонное правило
якорь меняется, и относительные ссылки обязаны сдвинуться на разницу якорей, а
абсолютные — на смещение блока. Первая версия сдвигала только абсолютные, и
копии смотрели в колонки сводки. Исправлено, откат `S8_CLONE_RB`.

## 5. Откаты

Каждая операция обратима, ключи в Script Properties:

| ключ | что откатывает |
|---|---|
| `S8_WIDTH_RB` | ширины колонок (`s8cwidthrollback`) |
| `S8_IDENT_RB` | исторические цвета шапок 736 (`s8cidentrollback`) |
| `S8_REPRO_RULES` | правила, воспроизводящие легаси-УФ на блоки |
| `S8_MASTER_CF_RB`, `S8_MASTER_CF_RB2` | правила эталона |
| `S8_RESTORE_RB` | до-данные диапазоны логических правил (`s8crestorerollback`) |
| `S8_GRAD_RB` | развязанные градиенты (`s8cgfixrollback`) |
| `S8_CLONE_RB` | копии «трафик без заказов» (`s8cclonerollback`) |
