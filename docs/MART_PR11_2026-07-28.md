# PR-Mart1.1 — реклама: raw + dedup_estimate в FACT_ADS_SKU_DAILY

**Дата:** 2026-07-28  **Статус:** готово к аудиту SQL → пере-bootstrap. Контракт: `MART_MART2_CONTRACTS_2026-07-28.md` §1.
**Файлы:** правка `sql/mart/pr_mart1_facts.sql` (блок FACT_ADS_SKU_DAILY в процедуре `sp_bootstrap_facts`) + `pr_mart1_validation.sql` §8.

## Что и зачем
Для ACOS/ROAS нужна выручка рекламы, а `sum_price`/`orders` — атрибутивные (мульти-тач, не аддитивны). Добавляем в
`FACT_ADS_SKU_DAILY` (грейн date×advert_id×nm_id, без смены грейна):
- `ads_revenue_raw_rub` = SUM(sum_price) — **source-faithful** (точно воспроизводит WB API; НЕ «авторитетная выручка»);
- `ads_revenue_dedup_estimate_rub` = Σ РАЗЛИЧНЫХ ненулевых sum_price в группе — **эвристическая ОЦЕНКА** (НЕ безусловный floor):
  для ненулевой выручки дедуп одинаковых значений даёт lower-bound-like оценку; для строк `sum_price=0 AND orders>0` точная
  дедупликация невозможна (используется обычный SUM(orders) — при мульти-тач может завышать; показывает `zero_revenue_multiorder_flag`);
- `ad_orders_raw` (**переим. из `orders`** — семантика та же, SUM по appType; downstream-потребителей ещё нет → не breaking);
- `ad_orders_dedup_estimate` = Σ MAX(orders) на различное ненулевое значение + orders строк с нулевой выручкой;
- `multitouch_ambiguous_flag` = (#строк с ненул. выручкой > #различных ненул. значений) — есть повтор атрибуции;
- `zero_revenue_multiorder_flag` = (≥2 строк appType с sum_price=0 И orders>0) — диагностика зоны неопределённости.
`ad_revenue_*`/`ad_orders_*` — ВНЕ любой консервации (ads-консервация — только stats_spend vs actual_spend, PR-Mart2b).

## Guards (добавлены в процедуру)
- parse-QC: + `sum_price` (к 7 прежним колонкам).
- **Динамический acceptance:** `Σ FACT.ads_revenue_raw_rub == Σ SAFE_CAST(source sum_price)` — БЕЗ фикс-суммы.
- **fail-closed границы estimate** (аудит): `COUNTIF(dedup<0 OR dedup>raw)` по revenue И orders = 0 — оценка не превышает
  source-faithful и неотрицательна (production-инвариант).
- Прежние: not-null grain, дедуп (date,advert,nm), empty>0, BUILD==source distinct grain, физика IS — без изменений.

## Проверено read-only (live, снимок текущий — числа растут)
n_rows==dk (грейн уникален), grain_null=0; `ads_revenue_raw_rub` == Σ source sum_price (dynamic acceptance держится);
dedup_estimate ≤ raw (в текущих данных raw≈1,767 млн, dedup≈1,654 млн — эвристическая оценка); ad_orders raw≈1973/dedup≈1839;
estimate-bounds (0≤dedup≤raw) нарушений = 0 (per-group проверено);
multitouch_ambiguous ≈118 групп; zero_revenue_multiorder=0. Исторический baseline 28.07: raw 1 759 917, дельта 1,12% (16 групп).
