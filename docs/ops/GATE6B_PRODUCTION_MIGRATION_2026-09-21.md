## Идемпотентность

Повторная запись в боевой лист **не выполнялась** — свойство уже доказано двумя реальными
прогонами в TEST. Вместо этого собран план заново на живом размере листа:

```
вставок 0 · дописываний 0 · значения идентичны · формулы идентичны · объединения идентичны
```

Условное форматирование в плане выросло с 434 до 868 запросов — это 434 снятия + 434 постановки:
УФ ставится **заменой**, а не добавлением. Результирующее число правил остаётся 434, что и
подтвердил реальный второй прогон в TEST (434 → 434).
