**Источники:**
- **Вес и габариты** — карточки Ozon `/v4/product/info/attributes`, снимок 04.09
  (`docs/ozon/audit_2026-09-04/forward_economics/api_snapshot_by_product_2026-09-04.csv`), сопоставлены с SKU через
  `REF_SKU_CHANNEL_MAP` (offer_id). Это вес, заявленный продавцом в карточке (упакованная единица), а не взвешивание.
  Крем для рук 0,391 кг совпадает с FACT модели сезона (`CONTROL_TOWER_MODEL_REVIEW.md:41`).
- ⚠️ Модель сезона считает лоты 25 кг по **допущениям** легче карточек: сыворотка 0,08 против 0,136, крем для лица
  0,105 против 0,161, пудра 0,14 против 0,125, тоник 0,215 против 0,200. Поэтому для мелких SKU она переоценивает,
  сколько штук входит в лот. Сама модель просит «Взвесить по одной коробке на ФФ».
- **Объём** — Ozon: `RAW_OZON_SUPPLY_BUNDLES.volume_in_litres`; WB: `RAW_WB_PAID_STORAGE.volume` (платное хранение);
  Usend: 0,00083 м³ на крем для рук (`USEND_LK_AUDIT_REVIEW_2026-09-09.md:47`).
- **HINT по коробке** (не записывается):
  - пудра — паллеты 3 630 = 33 × 110; строки поставок WB 2026: 110 × 6 раз, 220 × 1;
  - тоники — паллеты 3 600 = 40 × 90; строки WB 2026: 90 × 6, 180 × 1;
  - кремы 300 мл — паллеты 4 400 / 4 320 / 2 720 делятся на 40 (и на 80). Строки WB: 40 × 2 в 2026, кратные 40 в 2024–25 — но есть и 250 / 375 / 500 / 625;
  - сыворотки и кремы для лица — закономерности нет (35 / 70 / 105 рядом со 100 и 20; 75 рядом со 125).

  Паковочных листов в репозитории нет — это открытый пункт `ЧЕКЛИСТ_документов_к_претензии.md:16`.
  `supplier_box_amount` в `RAW_WB_SUPPLIES_GOODS` равен количеству строки поставки, а не вложению коробки.

## 5. Что будет записано после одобрения — черновик, заменён §8

- **Строки:** `evetis_ops.REF_SKU_LOGISTICS` — по строке на SKU × канал (`WB`, `OZON`) для 9 активных физических
  SKU. Для 2 неактивных — только поля, где есть факт. Наборы — если одобрите D2.
- **Даты:** `effective_from` = дата одобрения, `effective_to` = NULL.
- **Происхождение:** `source` = `C0_OWNER_APPROVED_<дата>`; в `note` — класс доказательства по каждому полю.
- **Пустые поля:** всё, что остаётся без ответа, записывается `NULL`. HINT не записываются никогда.
- **Как выполняется:** один `MERGE` из файла `sql/evetis_ops/ops_07_logistics_c0.sql` (в журнал движений не пишет),
  затем повторяется инвариант I16 (версии не пересекаются).
- **Лимиты 500 ед. и 200 л:** в текущей схеме полей нет (есть только `max_lot_weight_kg`) — нужно решение D9.
