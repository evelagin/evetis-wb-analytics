`pipelines/ozon/runtime/entities.py`). Ozon Seller Analytics («Заказано товаров», `/v1/analytics/data`

## Канон

Бизнес-дата заказа = `DATE(created_at, 'Europe/Moscow')` — одна и та же для одного отправления в FCT Ozon,
операционной модели, Юнитке и Control Tower. Сырой `created_at` (UTC) и RAW `order_date` остаются в RAW для
происхождения; RAW не переписывается, загрузчик Ozon (закреплённый образ) не меняется.

Выражение вычисляется ОДИН раз — там, где читается RAW-отправление, — и дальше едет со всей экономикой
отправления: заказ, отмена, цена/выручка, документированный выкуп, комиссия (факт и оценка), логистика по
posting_number, COGS (дата действия себестоимости), прочие прямые по posting_number, пара buyer/seller для СПП.
Реклама уже в МСК-сутках и не сдвигается; начисления только со sku (эквайринг, упаковка) — по дате начисления.
