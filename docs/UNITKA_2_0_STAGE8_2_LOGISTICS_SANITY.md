# UNITKA 2.0 — Stage 8.2 §8: знаменатель прямой логистики

Окно ставок D-30…D-1 от `LAST_CLOSED_DATE = 10.09.2026`, то есть **12.08–10.09.2026**.
Источник: `wb_raw.V_WB_FINANCE_CANONICAL`. Код: `apps-script/UnitkaS8b.gs` (`unitka2.0/v8.5.0`).

**Статус: дефект найден, исправление одобрено владельцем 11.09 и применено.**
Событийная модель B не менялась — менялась только популяция знаменателя.

---

## 1. В чём был дефект

Модель B считает `DIRECT = Σ прямых плеч / число отправлений`. Числом отправлений считались
`srid` **только с операцией «Логистика»**. Это неверно.

```
операция     строк   srid     сумма logistics_amount
Логистика     484    444      28 027,82 ₽
Доставка      165    153       9 811,10 ₽
пересечение srid между ними ....................... 0
```

**«Доставка» и «Логистика» — два взаимоисключающих имени одного события: прямой перевозки
отправления.** Доказательства, каждое замерено:

```
srid с операцией «Продажа» .......................... 545
из них имеют «Логистика» ............................ 404
из них имеют «Доставка» ............................. 141
404 + 141 = 545, продаж без транспортной строки ..... 0

комбинации плеч внутри srid:
  1 плечо  «Логистика» ............................. 404   продажа
  1 плечо  «Доставка» .............................. 141   продажа
  2 плеча  «Логистика, Логистика» ................... 40   отказ
  2 плеча  «Доставка, Доставка» ..................... 12   отказ
  смешанных схем внутри одного srid .................. 0
```

Каждая отправка несёт ровно одну схему, схемы внутри `srid` не смешиваются. Значит
разбиение «первое плечо — прямое, второе — обратное» работает в обеих схемах одинаково,
а корректная популяция отправлений окна — **597**, а не 444.

**Два дефекта сразу.** Деньги «Доставки» попадали в числитель **целиком** — включая
**оба** плеча её 12 отказов, то есть обратные плечи «Доставки» считались прямыми, — при
этом её 153 отправления в знаменатель не попадали.

```
было:  (26 738,82 прямых «Логистики» + 9 811,10 всей «Доставки») / 444 = 82,32 ₽
стало:  36 147,59 первых плеч по обеим схемам            / 597         = 60,55 ₽
```

Ориентир первого аудита — **60,37 ₽** — был верен.

## 2. Инвариант популяции

Проверяется **в коде при каждом прогоне** ставок, до записи; при несовпадении
`s8brates()` бросает исключение и ничего не пишет.

```
DIRECT SHIPMENTS = SALES + CANCELLED SHIPMENTS
            597  =  545  +  52                    PASS
```

Оба определения «отказной отправки» совпадают полностью: отправок без строки «Продажа» 52,
отправок с двумя плечами 52, их пересечение 52, исключений в обе стороны 0.

## 3. Итог по магазину

```
отправлений ........ 597  (Логистика 444 + Доставка 153)
продаж ............. 545        отказов ............ 52
первые плечи ....... 36 147,59 ₽  (в т.ч. «Доставка» 9 408,77 ₽)
вторые плечи ........ 1 691,33 ₽
вся логистика окна . 37 838,92 ₽ = первые + вторые, пересечение 0,00 ₽
DIRECT  = 36 147,59 / 597 = 60,5487 ₽ / валовый заказ
REVERSE =  1 691,33 /  52 = 32,5256 ₽ / отказ
```

Reverse leg остаётся отдельным членом по модели B и по-прежнему живёт в именованной
ячейке `REVERSE_LEG_RATE` (`WB737`). Значение изменилось с 32,225 на 32,53 ₽ — потому что
в популяцию вошли 12 отказов «Доставки», которых раньше не было.

## 5. Ответ на вопрос «почему крем для рук ~70, а Вишня и Амбра ~85–87»

Разброс был артефактом того же знаменателя. Разложим по компонентам так, как считала
старая модель (делитель — только `srid` «Логистики»):

| SKU | «Логистика» / N | «Доставка» / N | сумма | доля отправок по схеме «Доставка» |
|---|---|---|---|---|
| Крем для рук | 65,03 | 27,04 | 92,07 | 63 из 163 = 39 % |
| Крем Амбра | 54,80 | 35,08 | 89,88 | 9 из 13 = 69 % |
| Крем Вишня | 54,30 | 15,90 | 70,20 | 4 из 16 = 25 % |

Прямое плечо у Амбры и Вишни практически одинаковое — 54,80 и 54,30 ₽. Вся разница между
«70» и «90» бралась из того, **как часто** отправление ехало по схеме «Доставка»: эти
отправления добавлялись в числитель, но не в знаменатель.

На корректной популяции разброс исчезает: **Вишня 56,16 ₽, Амбра 54,11 ₽**, а крем для рук
честно дороже — **65,98 ₽**, потому что у него выше само прямое плечо (более крупная и
тяжёлая упаковка).

**Малая выборка остаётся отдельным риском.** У Амбры 21 отправление, у Вишни 20 при пороге
`n ≥ 10`; одно событие сдвигает ставку на 2–3 ₽. Порог обсуждается отдельно.
