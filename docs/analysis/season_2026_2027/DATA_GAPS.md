## 4. Чего нет и что запросить

1. **Сроки годности по партиям** (ФФ / упаковка) — определяет, нужен ли крему для рук сценарий 20/день с минусом.
2. **Свежий срез оперативной полки и наборов** от Usend после отгрузок 09.09 и перекладки.
3. **Подтверждение приёмки WB FBO** (слот, склад, коэффициент) — без него сентябрь–октябрь по WB не исполнимы.
4. **Стоимость и ETA партии 8** от поставщика; решение по партии крема АКНЕ (3 000–4 000).
5. **Сверка рекламы Ozon**: attributed_spend (41 тыс/авг) против отчёта кабинета (70 тыс за 2 мес) — какая часть без SKU.
6. **Реализованная цена WB по SKU** ежедневно (акции/автоскидки): нужен контроль «прайс vs факт», иначе экономика крема для рук уходит в минус незаметно.
7. **Ozon FBS** — в загрузке нет; если запускается — нужен `/v3/posting/fbs/list`.
8. **API Usend** (ключ + документация) — read-only слой `usend_raw`, чтобы остатки ФФ перестали восстанавливаться вручную.
