# control_tower/ — EVETIS Operational Control Tower v1 (09.09.2026)

Расчёт READ-ONLY (только SELECT к BigQuery, локальная модель). Ничего в production, кабинетах WB/Ozon, ставках, ценах и поставках не менялось. Все количества — рекомендации для ручного исполнения владельцем.

## С чего начать

1. `OWNER_HOME.md` — одна страница: статус дня, пять цифр, P0-действия, пять решений.
2. `TOMORROW_ACTION_PLAN.md` — 15 действий на 10.09 с количествами.
3. `NEXT_7_DAYS.md` → `NEXT_30_DAYS.md` — неделя и месяц по направлениям и вехам.
4. `OWNER_ACTION_QUEUE.csv` — полная очередь (P0–P4, дедлайн, SKU, кол-во, площадка, эффект, почему, статус).
5. `DAILY_OWNER_BRIEF.md` — шаблон ежедневной сводки + пример за 09.09.

## Термины

Карточка — позиция в заказе (набор = 1 карточка); флакон — физическая единица. Деньги продавца — GMV минус комиссия, эквайринг, логистика, хранение, реклама. Вклад — деньги продавца минус COGS проданного (до OPEX). Операционный результат — вклад минус OPEX (77 тыс/мес до февраля, 65 тыс с марта). Вклад никогда не называется чистой прибылью.
