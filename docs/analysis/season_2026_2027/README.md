## Как пересчитать

1. Обновить входные CSV (`wb_econ`, `wb_limits`, `wb_fin_monthly`, `wb_mart_monthly`, `wb_stock`, `wb_vel`, `ozon_*`) — SQL в комментариях к каждому файлу воспроизводится из `V_WB_SKU_FORWARD_ECONOMICS_CURRENT`, `V_ADS_SKU_ECONOMIC_LIMITS`, `V_WB_FINANCE_CANONICAL` (с обходом маппинга), `MART_SKU_DAILY`, `V_WB_STOCKS_T5_CURRENT`, `FACT_ORDERS`, `ozon_raw.*`.
2. Поправить в `model.py` константы фулфилмента (`FF_OPER`, `FF_LT`, `TRANSIT`) по свежему срезу.
3. `python3 model2.py` → папка `out/`.

## Термины

- **Карточка** — товарная позиция в заказе (набор = 1 карточка). **Флакон / базовая единица** — физический товар (набор из 3 = 3 флакона).
- **Деньги в бизнес (seller cash)** — GMV минус комиссия, эквайринг, логистика, хранение и реклама.
- **Вклад (contribution)** — деньги в бизнес минус себестоимость проданного. Маржа = вклад / GMV.
- **LOST_CLAIMED** — 3 467 карточек на поимённых складах WB (пожары), в претензии к РВБ; в продаваемый запас не входят.
